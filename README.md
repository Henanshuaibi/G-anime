# G 动漫 0.3

Android 8.0 及以上的轻量原生动漫播放器，包名 `cn.g.anime`。0.3 沿用原有签名和本机数据，可直接覆盖 0.1 / 0.2。

- 首页保留日漫、国漫入口与找番、追番、记录三个页面，增加最近观看的一键继续。
- 搜索框可补全最近 10 个搜索词；记录只存在本机，可在来源页清空。
- 多源搜索逐批显示结果，每个来源独立翻页。失败来源重试当前页，保留其他已找到的结果。
- 新搜索和页面切换会取消旧请求，旧回调不会覆盖新结果。
- 同名、同年和同地区条目合并，保留季数、配音版本及来源自己的 ID。
- 播放中换源会携带当前集数，在同名同年作品中匹配“第01集”“EP1”等编号，匹配不明确时不猜测。跨来源不复制时间进度，避免不同剪辑跳错位置。
- 长篇选集自动定位最近观看的范围并标记集数；从播放器返回详情后刷新续播按钮。播放页超过 90 集也按范围选择。
- 重试会重新请求播放地址，避免重复使用已经过期的地址。恢复进度完成后再开始播放。
- 播放页新增 0.75×、1×、1.25×、1.5×、2× 速度选择，全屏时也保留返回竖屏的按钮。
- 音频焦点变化时暂停，拔出耳机时暂停；字幕、音画同步及特定设备倍速行为仍需实机测试。
- 仅联网权限，不接广告或追踪 SDK，不加载第三方网页播放器。

| 暴风资源 | 开启，仅日漫 | 日漫样本未见明显广告；国漫样本有片中广告，因此不接入其国漫分类 | https://bfzyapi.com/api.php/provide/vod/ |

| 优质资源 | 关闭，手动备选 | 国漫和日漫样本片尾有博彩广告 | https://api.yzzy-api.com/inc/apijson.php |
| 魔都资源 | 关闭 | 日漫样本有博彩水印及片尾广告 | https://caiji.moduapi.cc/api.php/provide/vod/ |

来源页可开启或关闭备选源，显示抽查结论和来源链接。默认避免已确认含广告的来源及分类；手动开启备选源后可能看到其视频广告。为保证国漫、日漫都能找到内容，不能关闭某一类别最后一个已开启的来源。

**“抽查未见明显广告”不是“全部视频无广告”的保证。**0.2 阶段曾实际解码画面检查，已发现片尾、片中广告及烧录在画面内的博彩水印，详见 [SOURCE_AUDIT.md](SOURCE_AUDIT.md)。0.3 沿用该筛选策略，没有重新进行全部视频画面抽查。不依据接口能连通、清单中没有广告标签来声称无广告，不删除不确定的视频分片。没有逐集、逐帧或音频审查。

第三方内容授权未经逐条核实，来源标注不代表获得授权。应用不托管、上传或代理视频。提供方会收到正常网络连接所需的信息；链接可能失效或限地区。

收藏、记录和进度仅存本机，覆盖安装保留原有记录。长按收藏或记录可删除单条项目，在记录页可清空观看记录与进度。老版本的非凡、魔都来源 ID 及已有欧美/港台收藏的播放兼容性保留。

## 构建和验证

在已有 Android Java 构建工具的 Termux 中运行 `sh build.sh`，需要 `aapt2`、JDK、`zipalign` 和 `apksigner`。`GANIME_SDK_DIR` 指向含 `android.jar`、`android-res.jar`、`r8.jar` 的目录，默认复用相邻音乐项目的工具目录。

`GANIME_KEYSTORE`、`GANIME_SIGNING_PASSWORD_FILE` 指定本地签名材料，默认位于 `tools/`，构建前核对 `signing-certificate.sha256`。不要为覆盖更新重新生成密钥。产物为 `build/G-anime-0.3.apk`。

`sh tests/check.sh` 检查 URL、播放列表、集数匹配、续播位置、类别准入、搜索分组、独立分页及默认广告来源策略。`sh tests/check.sh --live` 额外验证五个来源的目录、名称搜索、详情、HLS 清单和视频分片。主机测试需将 Maven Central 的 `org.json:json:20240303` 放在 `tools/json.jar`，不打入 APK。

签名材料、SDK、依赖、构建产物、媒体抽样和本地数据不进入 Git 或源码 ZIP。手机界面、声音、全屏及续播仍需实机验收；主机解码抽样不代表应用内播放器已在手机上验证。
