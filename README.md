# G 动漫 0.1

面向 Android 8.0 及以上的轻量原生动漫播放器，包名 `cn.g.anime`。

- 按日韩、国产、欧美、港台动漫浏览，支持按名称搜索和翻页。
- 内置非凡资源、魔都资源两个第三方公开接口，可以切换来源搜索。
- 详情、播放及来源说明页标明提供方，保留原站链接。
- 只使用接口中 HTTPS 的 HLS/MP4 视频地址；不运行来源脚本，不嵌入网页播放器。
- 选集、线路选择、自动下一集、横竖屏切换及系统播放控制。
- 收藏、最近观看和按集续播只存于本机，各保留最近 200 条记录。
- 应用免费，不接入广告、收费或追踪 SDK，仅申请联网权限。

## 资源来源与限制

| 提供方 | 原站 | JSON 数据接口 |
| --- | --- | --- |
| 非凡资源 | https://ffzy.tv/ | https://api.ffzyapi.com/api.php/provide/vod/ |
| 魔都资源 | https://www.moduzy.net/ | https://caiji.moduapi.cc/api.php/provide/vod/ |

应用不托管、上传或代理视频。第三方接口的内容授权、地区可用性及视频内广告未经逐条核实；**标注来源不代表获得播放或分发授权**。应用自身没有广告，无法保证第三方视频片头、视频画面或原站页面没有广告。来源可能失效，原站跳转由用户主动触发。

只允许来源中明确列出的四类动漫 ID，搜索结果也进行相同筛选，排除影视、综艺及成人分类。源站分类本身的准确性由源站决定。新来源需要核实类别 ID 后修改 `Source.java`，没有远程脚本和代码更新功能。

图片、目录和视频由提供方直接响应，提供方会收到正常网络连接所需的信息。卸载应用会删除本地收藏和记录；可在足迹页清空记录与进度。长按收藏或记录可移除单条项目。

## 构建

在已有 Android Java 构建工具的 Termux 中运行 `sh build.sh`，需要 `aapt2`、JDK、`zipalign` 和 `apksigner`。本地 SDK 默认复用相邻音乐项目的工具目录，可通过 `GANIME_SDK_DIR` 指向含有 `android.jar`、`android-res.jar`、`r8.jar` 的目录。

签名文件通过 `GANIME_KEYSTORE` 与 `GANIME_SIGNING_PASSWORD_FILE` 指定，默认位于本项目 `tools/`。首次生成的证书公开指纹记录在 `signing-certificate.sha256`，构建前核对以保证后续原位更新。签名密钥和口令必须在本地备份，不进入 Git 或源码归档。公开源码不含 SDK、构建产物、依赖二进制或签名材料。

产物：`build/G-anime-0.1.apk`。

## 验证

`sh tests/check.sh` 运行 URL、播放列表、来源类别与进度键隔离检查。

`sh tests/check.sh --live` 额外使用与客户端相同的 Java 目录/搜索/详情请求代码，获取两个来源的 HLS 主清单、媒体清单及视频分片前 64 KiB，结果写入 `build/live-check.json`。需要将 Maven Central 的 `org.json:json:20240303` 放入本地 `tools/json.jar`，仅用于主机测试，不打入 APK。

APK 的签名、包名、版本和对齐可在构建时验证。网络资源抽样通过不代表所有集数均可播放，也不能证明设备解码、音画同步、续播、触控及全屏操作正常；这些仍需安装后在手机上验证。
