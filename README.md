# G 动漫 0.2

Android 8.0 及以上的轻量原生动漫播放器，包名 `cn.g.anime`。0.2 沿用 0.1 的签名和本机数据，可直接覆盖安装。

- 首页直接切换日漫、国漫；底部仅保留找番、追番、记录三个入口。
- 名称搜索同时查询已开启的来源，逐批显示结果，合并同名、同年份和同地区条目。
- 保留季数、配音版本及不同年份，避免合并成错误的动漫；来源自己的 ID 始终保留。
- 详情可切换播放源，播放失败后也能直接返回多源搜索。
- 超过 90 集的长篇分段选集；收藏、观看记录、逐集续播、自动下一集及横竖屏播放沿用。
- 仅联网权限，不接广告或追踪 SDK，不加载第三方网页播放器。

来源页可开启或关闭备选源，显示抽查结论和来源链接。默认避免已确认含广告的来源及分类；手动开启备选源后可能看到其视频广告。为保证国漫、日漫都能找到内容，不能关闭某一类别最后一个已开启的来源。

**“抽查未见明显广告”不是“全部视频无广告”的保证。**本次实际解码画面检查，已发现片尾、片中广告及烧录在画面内的博彩水印，详见 [SOURCE_AUDIT.md](SOURCE_AUDIT.md)。不依据接口能连通、清单中没有广告标签来声称无广告，不删除不确定的视频分片。没有逐集、逐帧或音频审查。

第三方内容授权未经逐条核实，来源标注不代表获得授权。应用不托管、上传或代理视频。提供方会收到正常网络连接所需的信息；链接可能失效或限地区。

收藏、记录和进度仅存本机，覆盖安装保留原有记录。长按收藏或记录可删除单条项目，在记录页可清空观看记录与进度。老版本的非凡、魔都来源 ID 及已有欧美/港台收藏的播放兼容性保留。

## 构建和验证

在已有 Android Java 构建工具的 Termux 中运行 `sh build.sh`，需要 `aapt2`、JDK、`zipalign` 和 `apksigner`。`GANIME_SDK_DIR` 指向含 `android.jar`、`android-res.jar`、`r8.jar` 的目录，默认复用相邻音乐项目的工具目录。

`GANIME_KEYSTORE`、`GANIME_SIGNING_PASSWORD_FILE` 指定本地签名材料，默认位于 `tools/`，构建前核对 `signing-certificate.sha256`。不要为覆盖更新重新生成密钥。产物为 `build/G-anime-0.2.apk`。

`sh tests/check.sh` 检查 URL、播放列表、类别准入、搜索分组及默认广告来源策略。`sh tests/check.sh --live` 额外验证五个来源的目录、名称搜索、详情、HLS 清单和视频分片。主机测试需将 Maven Central 的 `org.json:json:20240303` 放在 `tools/json.jar`，不打入 APK。

签名材料、SDK、依赖、构建产物、媒体抽样和本地数据不进入 Git 或源码 ZIP。手机界面、声音、全屏及续播仍需实机验收；主机解码抽样不代表应用内播放器已在手机上验证。
